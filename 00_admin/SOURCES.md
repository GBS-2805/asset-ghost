# Resources — 4-app loadout

Grouped by what feeds each app. Cross-app entries listed once under feeding primary.
Rules unchanged: license-first (`LICENSES.md`), one format, one copy.

## Billfish (the vault's visual layer)
- [Billfish](https://billfish.cn/) — free asset manager (Win/Mac); library points at this vault's folders; exclude 80_private. Note: billfish.org is a fishing-conservation charity, NOT the app
- [Eagle](https://eagle.cool/) — the polished paid alternative ($34.95 one-time, 2 devices, lifetime updates, 30-day trial) — reads the same folders, swaps in later with zero migration

## Figma (UI / app / web)
- [Figma Community](https://figma.com/community) — free kits/templates; start every project here
- [Untitled UI](https://www.untitledui.com/) — largest Figma UI kit/design system (free tier + paid)
- [awesome-figma (brandonhimpfen)](https://github.com/brandonhimpfen/awesome-figma) — curated plugin directory
- [Iconify](https://iconify.design/) — 100k+ open-licensed icons, plugin imports straight in
- [Blush](https://blush.design/) — customizable artist illustrations (Figma plugin)
- [Shader Gradient](https://shadergradient.co/) — animated gradients (Figma/Framer/React)
- [Themer](https://www.figma.com/community/plugin/840813540411310627) — design-token themes
- [Framer](https://framer.com/) / [Webflow](https://webflow.com/) — no-code publish path; [Carrd](https://carrd.co/) for one-pagers

## Illustrator (vector / posters)
- [Inkscape](https://inkscape.org/) — free SVG editor, print-friendly fallback
- [Fontshare](https://www.fontshare.com/) — free professional fonts (check each face's terms)
- [Google Fonts](https://fonts.google.com/) — OFL library
- [Fontpair](https://www.fontpair.co/) — pairing ideas
- [The Mockup Club](https://themockup.club/) — free mockups (PS/Sketch/Figma/XD)
- [Blobmaker](https://www.blobmaker.app/) / [Squircley](https://squircley.app/) — instant organic SVG shapes
- [Lummi](https://www.lummi.ai/) — AI-free-licensed stock images/illustrations
- Print: paper stock test + bleed templates belong in `70_poster/print-presets/`

## Plasticity (3D CAD, personal)
- [Official docs](https://doc.plasticity.xyz/) — start with the learning path
- [Plasticity Discord](https://discord.gg/plasticity) — releases + fastest support
- [Academic license FAQ](https://www.plasticity.xyz/faq) — application + eligibility
- [NX Student Edition](https://trials.sw.siemens.com/nx-student-edition) — career track, later (see APPS.md)
- Fusion habits carry: Parasolid behavior identical; skip history, model direct

## Blender (3D illustration)
- [nijiGPen](https://github.com/chsh2/nijiGPen) — Grease Pencil illustration add-on (3.3–5.3)
- [Grease Pencil Tools](https://github.com/Pullusb/greasepencil_tools) — QoL + Pepeland brushes
- [Malt / BEER](https://github.com/bnpr/Malt) — NPR render engine for illustration-style output
- [awesome-blender](https://github.com/agmmnn/awesome-blender) — the add-on ecosystem index
- [Poly Haven](https://polyhaven.com/) — CC0 HDRIs/textures/models
- [BlenderKit](https://www.blenderkit.com/) — in-Blender asset browser (free tier)
- [ambientCG](https://ambientcg.com/) — CC0 PBR textures
- [Grease Pencil docs](https://docs.blender.org/manual/en/latest/grease_pencil/index.html) — GP 3.0 official manual
