LICENSE file in the repo root — the license-first rule applies the same as anywhere.

## Maintenance filter (paste onto any search)

- `pushed:>2025-01-01` — active within ~the last year
- `stars:>100` (raise for abundant niches, lower for niche ones)
- `license:mit` / `license:cc0` / `license:gpl` — GitHub filters by license
