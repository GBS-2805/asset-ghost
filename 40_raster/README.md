## ⚡ The overlay trick (the "expensive poster" look)

1. Open your poster/vector work
2. Place an overlay PNG **on the top layer** (drag onto canvas)
3. Set blend mode:
   - **Multiply** → grunge, scratches, paper texture (darkens)
   - **Screen** → dust, sparks, light leaks (lightens)
4. Drop opacity to **10–30%** — subtle wins
5. Want it only on part? Mask it.

Multiply + Screen. That's the whole trick.

## 🏷 Sticker / mockup flow (PSD)

1. Open the `.psd` in the mockup app (Photoshop/Photopea — Photopea is free, runs in browser)
2. Double-click the **smart object** layer
3. Drop your art in → save → the mockup updates
4. Export PNG → done
